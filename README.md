## S3 Helper

A project for learning S3

Вместо S3-хранилища используется moto\[server].
Модификатор \[server] позволит поднять moto как отдельный сервер 
```bash
   moto_server -p 5000
```

Когда boto3 делает запрос (например, s3.create_bucket), он отправляет HTTP-запрос по сети.
Библиотека moto работает как «перехватчик» (mock). Moto перехватывает все запросы boto3 и отвечает на них из оперативной памяти, имитируя поведение реального AWS S3 или MinIO.
